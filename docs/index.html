🌙 CachyOS Noctalia Setup

A minimal, fast, and elegant script to set up your CachyOS-based development environment with the Noctalia dark theme.

🚀 Getting Started

Clone the repo and run the script:

git clone https://github.com/Jhonatanmizu/cachyos-noctalia-setup.git
cd cachyos-noctalia-setup
chmod +x setup.sh
./setup.sh

⚙️ What it Does

  • 📦 Installs essential packages and tools via pacman + AUR
  • 🧩 Configures GTK theme and icon theme for the Noctalia look
  • 🛠️ Applies dotfiles using stow
  • 🌙 Applies the Noctalia dark theme (Catppuccin Mocha + Tela)
